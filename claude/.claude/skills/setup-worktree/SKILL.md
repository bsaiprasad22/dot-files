# Setup Worktree

Initialize worktree with Jira integration - create or link ticket, setup branch, install deps.

## Usage

```
/setup [task description] [options]
```

### Options

- `--jira=<ID>` - Use existing Jira ticket (e.g., INFRA-1234)
- `--repo=<path>` - Base repo path (default: /home/vm/penops-ui)
- `--project=<key>` - Jira project (default: INFRA)
- `--priority=<P0-P5>` - Priority level (default: P2)
- `--classification=<label>` - Classification label
- `--parent=<EPIC-ID>` - Parent epic
- `--requestor=<email>` - Requestor email (optional)
- `--no-jira` - Skip Jira, just create worktree

## Instructions

### 1. Parse Input

Extract task description from command args. Generate summary/description automatically.

### 3. Jira Ticket Resolution

```bash
# Verify ticket exists
curl -s -u "$JIRA_AUTH" \
  "https://pensando.atlassian.net/rest/api/3/issue/INFRA-1234" \
  | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['key'], d['fields']['summary'])"
```

### 4. Create Worktree

```bash
JIRA_ID="INFRA-1234"
BASE_REPO="/home/vm/penops-ui"
WORKTREE_PATH="/home/vm/worktrees/${JIRA_ID}"

cd "$BASE_REPO"
git fetch origin
git worktree add "$WORKTREE_PATH" -b "$JIRA_ID" origin/main
```

### 5. Install Dependencies

Detect project type and install:

```bash
cd "$WORKTREE_PATH"

# penops-ui requires legacy-peer-deps
if [[ -f "package.json" ]]; then
  if [[ "$BASE_REPO" == *"penops-ui"* ]]; then
    npm install --legacy-peer-deps
  else
    npm install
  fi
fi

# Python
if [[ -f "requirements.txt" ]]; then
  python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
fi

# Go
if [[ -f "go.mod" ]]; then
  go mod download
fi
```

### 6. Transition Jira to In Progress

```bash
# Get transitions, find "In Progress", execute
TRANSITIONS=$(curl -s -u "$JIRA_AUTH" \
  "https://pensando.atlassian.net/rest/api/3/issue/${JIRA_ID}/transitions")

IN_PROGRESS_ID=$(echo "$TRANSITIONS" | python3 -c "
import sys,json
for t in json.load(sys.stdin)['transitions']:
  if 'progress' in t['name'].lower(): print(t['id']); break
")

curl -s -u "$JIRA_AUTH" -X POST -H "Content-Type: application/json" \
  "https://pensando.atlassian.net/rest/api/3/issue/${JIRA_ID}/transitions" \
  -d "{\"transition\": {\"id\": \"${IN_PROGRESS_ID}\"}}"
```

## Error Handling

- Repo not found: prompt for path
- Jira creation fails: show error, offer retry
- Worktree exists: ask reuse or abort
- Deps install fails: warn, continue
- Transition fails: warn, continue
